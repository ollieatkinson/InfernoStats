# Inferno Stats

A plugin to give you in-depth stats about your inferno attempt.

The **Wave Tool** setting chooses where clicking a saved wave opens its spawns. Select **Inferno Tips** to explore them at [los.inferno.tips](https://los.inferno.tips/). Existing Line of Sight and Trainer options are unchanged. Inferno Tips supports Inferno waves; player position, pillars and NPC ordering are practice defaults because they are not included in the saved-wave link.
